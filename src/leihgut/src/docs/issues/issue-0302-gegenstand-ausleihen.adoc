== Beschreibung

Thekendienst leiht einen verfügbaren Gegenstand an ein Mitglied aus.
Kaution wird hinterlegt, Zustandswechsel wird im Audit protokolliert.

== Akzeptanzkriterien

[source,gherkin]
----
Given ein verfügbarer Gegenstand, ein nicht gesperrtes Mitglied
When POST /ausleihen mit gegenstandId, mitgliedId, ausgabedatum
Then 201 mit ausleiheId, rueckgabefrist = ausgabedatum + leihdauer_tage
And Gegenstand.zustand = "ausgeliehen"
And Kautionsbewegung "hinterlegung" vorhanden
----
